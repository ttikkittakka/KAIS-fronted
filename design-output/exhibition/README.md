상단에 프로젝트 주제, 어떡하조, 하소윤·노준상, 배재용 멘토를 표시했습니다. 제품 화면은 공개 체험 경로에서 캡처한 예시 화면입니다. 설계는 제공된 JPG의 구성과 서체를 참고해 120 × 130 cm에 맞춰 배치했습니다.

재출력할 때는 100% 배율과 사용자 지정 1200 × 1300 mm를 선택합니다. 소스는 `build_panels.py`입니다. 앱 스크린샷을 `home.png`, `diary.png`, `entry.png`, `mission.png`, `map.png`, `guardian.png`로 캡처해 `--screens` 폴더에 둡니다. `--font`에는 [Pretendard Variable TTF](https://github.com/orioncactus/pretendard)를 지정할 수 있습니다.
